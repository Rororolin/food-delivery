Пошаговая инструкция
1 Распаковка архива

Распакуйте скачанный архив с программой в удобную папку на вашем компьютере. Рекомендуется использовать путь без кириллицы и пробелов.

2 Запуск серверов

Выберите удобный для вас способ запуска:

  • Автоматический запуск — используйте start-all.bat для одновременного запуска всех трёх серверов в отдельных окнах
  • Раздельный запуск — запустите каждый сервер отдельно через соответствующие .exe файлы
start-all.bat // Запуск всех серверов Линуксоед
food-delivery\food-delivery.exe // Клиент (порт 8080)
food-delivery-admin\food-delivery-admin.exe // Админ (порт 8081)
food-delivery-courier\food-delivery-courier.exe // Курьер (порт 8082)
3 Работа с приложением

После успешного запуска серверов откройте браузер и перейдите по нужной ссылке из раздела "Быстрый доступ" выше. Убедитесь, что все серверы запущены и работают корректно.

💡 Полезные советы
  • Не закрывайте окна серверов во время работы с приложением Линуксоед
  • Используйте современные браузеры (Chrome, Firefox, Edge) для лучшей производительности
  • При возникновении ошибок перезапустите серверы через start-all.bat
  • Проверьте, что порты 8080, 8081 и 8082 свободны перед запуском
