**1. Распаковка архива**

Распакуйте скачанный архив с программой в удобную папку на вашем компьютере.

Рекомендуется использовать путь без кириллицы и пробелов.

**2. Запуск серверов**

Выберите удобный способ запуска.

Автоматический запуск

Используйте файл: start-all.bat

Он запускает все три сервера одновременно в отдельных окнах.
Раздельный запуск
Можно запустить каждый сервер отдельно:
food-delivery\food-delivery.exe

Клиентская часть — порт 8080.
food-delivery-admin\food-delivery-admin.exe

Административная часть — порт 8081.
food-delivery-courier\food-delivery-courier.exe

Курьерская часть — порт 8082.

**3. Работа с приложением**

После успешного запуска серверов откройте браузер и перейдите по нужному адресу:
- клиентская часть — http://localhost:8080
- административная часть — http://localhost:8081
- курьерская часть — http://localhost:8082
Перед началом работы убедитесь, что все необходимые серверы запущены и работают без ошибок.
